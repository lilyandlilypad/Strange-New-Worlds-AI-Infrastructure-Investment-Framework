# Strange New Worlds: AI Infrastructure Investment Framework

## A 30-year public thesis test

This project tracks a $10,000 investment thesis testing whether AI infrastructure—compute,
chips, and manufacturing—will capture more long-term value than the applications built on top.

**Core thesis:** Infrastructure > applications · Hardware > software · Chips > code

The framework explores a transition from centralized cloud AI toward personal and distributed
AI compute. It is a long-term hypothesis to evaluate, not a guaranteed outcome.

## Tracking milestones

- January 1, 2027: First scheduled quarterly tracking checkpoint.
- Quarterly thereafter: Review on January 1, April 1, July 1, and October 1; compare each quarter with the same quarter in the prior year.
- December 31 annually: Review the full year alongside Q4 and compare year-end results with the prior year.
- October 2031: Five-year review.
- October 2036: Ten-year review.
- October 2056: Thirty-year review.
