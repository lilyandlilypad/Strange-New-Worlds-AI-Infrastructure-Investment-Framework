# Lily seasonal logos

Add your four lily logo images to this folder using these exact PNG filenames:

- `spring.png` — March, April, or May
- `summer.png` — June, July, or August
- `fall.png` — September, October, or November
- `winter.png` — December, January, or February

The homepage chooses the image from the page's last-modified timestamp interpreted in the
`America/New_York` time zone. These are meteorological season boundaries. Until the matching
image is added, the logo is hidden; the author name and timestamp remain visible.
