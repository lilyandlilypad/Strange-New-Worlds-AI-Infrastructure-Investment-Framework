# Portfolio and Investment Overview

A 30-Year Public Thesis Test

Testing whether infrastructure dominates applications in the AI era through a $10,000 investment portfolio tracked over 30 years.

## 🎯 The Thesis
Infrastructure > Applications

Hardware > Software  

Chips > Code

Every era of computing follows this pattern:

- IBM Mainframes → Personal Computers

- Cloud Centralization → Personal Data Centers (happening now)

- Nvidia/TSMC will capture 80%+ of value

- Applications are impressive but dependent
