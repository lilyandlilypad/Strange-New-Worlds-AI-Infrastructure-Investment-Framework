## Why Infrastructure Always Dominates
1. Control of Scarcity
Infrastructure controls WHAT CAN EXIST.

Personal Computing Era:

- You can't compute without Intel chips

- You can't build without Windows OS

- Intel/Microsoft set the rules

- Everyone else is dependent

Personal Data Center Era:

- You can't run AI without GPUs

- You can't do mobile AI without Snapdragon/Apple Silicon

- Infrastructure owners control the rules

- Applications are dependent renters
2. Margin Capture
Infrastructure captures margins at every level:

Hardware layers:

├─ Nvidia RTX Spark: $2,000-4,000 per device

├─ Qualcomm Snapdragon X AI: Cost to manufacturers

└─ TSMC manufacturing: Captured upfront

Application layers:

├─ OpenAI: Pays per GPU, not per API call

├─ Anthropic: Dependent on cloud compute pricing

└─ Your app: Rent hardware, capture thin margins

Example: If Nvidia charges $3,000 for GPU in consumer device

- Device sells for $1,500

- Nvidia captured 200% of end-user value at hardware layer

- Applications split remaining margin
3. Mandatory Adoption
Infrastructure: Must-have (no alternatives)

├─ Everyone needs compute

├─ Everyone uses the dominant chip/OS

├─ Market penetration: 90%+

└─ Forced adoption

Applications: Nice-to-have (many alternatives)

├─ Many ways to do the same thing

├─ Market penetration: varies

├─ Optional adoption
